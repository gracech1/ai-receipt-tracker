# Project Title

## 1) Brief Summary
One of my new year's resolutions is to track my spending more responsibly. This receipt-tracking application helps me to easily store and analyze my spending. It utilizes to tabscanner API to directly parse information out of receipts and autofill it into the dashboard. 

## 2) Features Included
- Adding entries manually and using image-based OCR
- Checks to ensure that user has filled out form correctly
- UI for a table which can be filtered based on date range and category, deleting entires
- Responsive charts that show spending in different categories and over time

## 3) Time Spent Developing
Spent about 20 hours starting from last week!
